# تجربه قهوه لوکس

Create a premium, modern, minimalist Persian coffee e-commerce website with a fully RTL (Right-to-Left) layout.

The website is an online store focused specifically on selling coffee beans and ground coffee.

The entire website must be written in Persian (Farsi), with all UI elements, navigation, product information, buttons, forms, and interactions designed natively for RTL.

Do NOT include coffee drinks, café ordering, coffee equipment, coffee machines, travel-related content, or blog sections.

The visual direction should be inspired by the provided coffee website reference image.

The design should feel:

Luxury
Dark
Minimal
Modern
Editorial
Cinematic
Sophisticated
Premium
Product-focused

The website should feel like a high-end specialty coffee brand rather than a generic online store.
